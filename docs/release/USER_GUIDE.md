# Humanities Debate 설치·사용 안내

이 파일은 0.0.11-rc.1 배포 전 검증 후보의 안내입니다. 아직 정식 배포 승인을 받은 설치 파일이 아닙니다. SK하이닉스 공식 서비스·채용 평가 도구가 아닙니다.

1. Windows x64와 Google Chrome 정식 버전, 인터넷 연결, 이용 가능한 본인 ChatGPT 계정을 준비합니다. 별도 Node.js·VS Code·터미널은 필요하지 않습니다. 다른 PC·Windows 버전에서의 작동을 모두 보장하지 않습니다.
2. 승인된 Organization Release에서 받은 파일인지, 파일명·버전·SHA-256이 안내와 일치하는지 확인합니다. Microsoft Defender로 검사하세요. 서명 없는 파일은 SmartScreen 경고가 나올 수 있습니다. 보안 기능을 끄거나 무조건 경고를 무시하지 마세요. 출처를 신뢰하지 못하면 실행하지 않습니다.
3. 기존 앱에서는 진행 토론을 끝내고 설정의 기록 백업을 먼저 만듭니다. 구버전을 종료합니다. 후보를 검증할 때는 기존 설치 폴더를 덮어쓰지 말고 별도 폴더를 선택하세요. 이번 준비 작업은 기존 앱을 자동 설치·제거하지 않습니다.
4. 설치 마법사를 실행해 본인 계정용으로 설치하고 바탕화면 또는 시작 메뉴의 Humanities Debate를 엽니다.
5. Continue with ChatGPT로 본인의 계정·작업공간을 선택하고 구독 사용 권한에 직접 동의합니다. 비밀번호·토큰·Chrome 프로필 폴더를 개발자에게 보내지 마세요. 모델 접근과 사용량은 계정·작업공간·동의 내용에 따라 달라집니다.
6. Windows와 앱의 Chrome 프로필에서 마이크를 허용합니다. 실패하면 텍스트 입력으로 참여할 수 있습니다. Chrome 음성 서비스는 인터넷이 필요할 수 있습니다.
7. 주제·일반/심화 수준·대기 시간·일반/실전 표시 모드를 선택하고 토론을 시작합니다. 말하기로 AI 준비를 취소하고, 인식한 내용을 확인·수정한 뒤 발언을 완료합니다.
8. 종료 후 전체 기록을 읽고 필요할 때 AI 피드백 분석을 실행합니다. 분석은 추가 AI 사용량을 사용합니다. 이미 저장한 피드백 열람은 재분석을 요청하지 않습니다. 평가는 연습용이며 실제 채용 결과를 예측하지 않습니다.
9. 설정에서 계정 추가·전환·로그아웃·ChatGPT 사용량 관리·기록 백업을 사용할 수 있습니다. 한도 오류에는 자동으로 다른 계정·모델·유료 API를 사용하지 않습니다. 다른 계정으로 시험하지 않은 동작은 미검증입니다.
10. Chrome 메인 창을 닫거나 설정의 완전 종료를 사용합니다. 제거는 Windows 설정 → 앱 → 설치된 앱에서 진행합니다. 제거 시 기록 폴더를 지우도록 구성하지 않았지만, 삭제·재설치·업데이트 전 본인 기록 백업을 권장합니다.

앱 데이터는 기본적으로 `%APPDATA%\HumanitiesDebateSIWC\profiles` 아래에서 Windows 사용자·앱 프로필·검증된 ChatGPT 연결별로 분리됩니다. 토론은 계정별 전용 Chrome 프로필에 로컬 저장되며 인증정보는 Windows 보호 저장소로 암호화합니다. 앱 폴더 전체나 인증 파일을 옮겨서 다른 사람에게 전달하지 마세요. 토론 백업 JSON에도 개인정보가 들어갈 수 있습니다.

홈페이지: https://humanities-debate.github.io/ — 현재 설치 파일 다운로드는 준비 중입니다. 이 문서에 아직 없는 Release 주소를 임의로 조합해 사용하지 마세요.
