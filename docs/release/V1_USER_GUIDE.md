# Humanities Debate 1.0.0 설치·사용 안내

Windows x64용 비공식 인문학 토론 연습 프로그램입니다. SK하이닉스 공식
서비스나 채용 평가 도구가 아닙니다. 이번 설치 파일은 사용자 실행 확인 전까지
로컬에서 보관하며 공개 다운로드는 활성화하지 않습니다.

1. Windows x64, Google Chrome 정식 버전, 인터넷과 적격 본인 ChatGPT 계정을
   준비합니다. 설치 후 VS Code·Node.js·터미널·개발자 API 키는 필요하지 않습니다.
2. 공개 후에는 홈페이지가 연결하는 실제 Organization Release에서 받습니다.
   파일명 `HumanitiesDebate-Setup-1.0.0-x64.exe`와 제공한 SHA-256을 비교하고
   Microsoft Defender로 검사합니다. 미서명 앱은 SmartScreen 경고가 나타날 수
   있습니다. 보안 기능을 끄지 말고 출처를 신뢰하지 못하면 실행하지 마세요.
3. 기존 앱에서 토론을 끝내고 설정에서 기록을 백업한 뒤 앱을 종료합니다.
   RC와 동시에 실행하지 마세요. 첫 검증 시 별도 설치 폴더를 선택합니다.
   기존 EXE와 기록을 지우거나 인증 폴더를 수동 이동하지 않습니다.
4. 설치 마법사를 실행해 본인 Windows 계정용으로 설치하고 바탕화면 또는
   시작 메뉴에서 Humanities Debate를 실행합니다.
5. 처음 필요할 때 Continue with ChatGPT로 본인 계정·작업공간에 로그인하고
   구독 사용에 동의합니다. 사용량은 본인 계정의 자격·한도에 따릅니다.
   비밀번호·인증 토큰·인증 폴더를 개발자에게 보내지 마세요.
6. Windows와 앱 전용 Chrome 프로필에서 마이크를 허용합니다. 권한·서비스
   문제로 인식되지 않으면 텍스트 입력을 이용합니다. Chrome 음성 처리는
   인터넷을 이용할 수 있으며 오프라인 처리를 보장하지 않습니다.
7. 주제와 일반/심화 토론, 대기 시간, 일반/실전 표시 모드를 선택해 시작합니다.
   말하기 버튼으로 AI 준비를 중단하고, 인식 결과를 확인·수정해 발언을 완료합니다.
8. 종료 후 전체 발언을 확인하고 원할 때 100점 피드백을 요청합니다. 분석은
   추가 AI 사용량을 사용합니다. 이미 저장된 기록·피드백 열람은 재호출하지 않습니다.
9. 설정에서 계정 전환·로그아웃·사용량 관리·기록 백업/복원을 이용합니다.
   한도에 도달하면 자동으로 다른 계정·모델·유료 API로 바꾸지 않습니다.
10. Chrome 메인 창을 닫거나 설정의 완전 종료로 종료합니다. 제거는 Windows
    설정 → 앱 → 설치된 앱에서 합니다. 데이터 자동 삭제는 비활성화했지만,
    업데이트·제거·재설치 전에 본인이 만든 기록 백업을 보관하세요.

데이터는 `%APPDATA%\HumanitiesDebateSIWC\profiles` 아래 Windows 사용자·앱
프로필·검증된 ChatGPT 연결별로 분리합니다. 토론은 계정별 Chrome 로컬 저장소,
토큰은 Windows 보호 저장소로 보관합니다. 기록은 별도 암호화 금고가 아니며
같은 Windows 계정을 여러 사람이 공유하는 것은 안전한 사용자 분리를 대신하지 않습니다.

앱 독립 코드는 MIT, 포함된 SIWC DevKit과 수정 모듈은 별도의 비상업 라이선스입니다.
전체 설치판의 상업적 재사용을 허용하는 단일 MIT 배포가 아닙니다. 설치된
`resources/licenses/`의 원문·범위·제3자 고지를 확인하세요.
