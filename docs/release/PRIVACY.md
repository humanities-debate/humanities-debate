# 개인정보·음성·AI 사용 안내

- 비공식 개인 연습 도구입니다. 사용자가 직접 공식 OpenAI 페이지에서 로그인하며 앱·개발자는 ChatGPT 비밀번호를 요구하지 않습니다. 구독 사용은 본인 계정의 자격·동의·한도에 따릅니다. 로그인 성공만으로 무제한·무료 AI 사용을 보장하지 않습니다.
- AI 토론과 피드백을 요청하면 주제·발언 및 분석 대상 기록이 OpenAI로 전송됩니다. 현재 Responses 요청은 `store: false`이며 이것이 서비스 제공자의 모든 처리·보관을 없애는 보장은 아닙니다. 회사 기밀·비밀번호·제3자의 개인정보를 입력하지 마세요.
- Chrome Web Speech API는 Google 등 브라우저 제공자의 온라인 음성 처리를 사용할 수 있습니다. 완전한 오프라인 음성 인식이 아니며 인터넷·권한·서비스 상태에 영향을 받습니다. 앱에서 별도의 음성 녹음 파일 저장 기능은 제공하지 않습니다.
- 인증 토큰은 앱의 Windows 보호 저장소로 암호화해 로컬 보관하며 Chrome UI나 웹 저장소에 전달하지 않습니다. 계정·등록 ID를 검증한 뒤 토론 저장 영역을 나눕니다. 같은 Windows 계정의 악성 프로그램·관리자·물리적 디스크 접근까지 완전히 차단하지는 않습니다.
- 토론 원문·평가·백업은 사용자 PC에 저장됩니다. 토론 기록은 별도 암호화된 금고가 아닙니다. 앱 사용자가 직접 복사·삭제·백업할 수 있으므로 공유 PC와 백업 파일 보관에 주의하세요. 같은 Windows 계정을 여러 사람이 공유하는 것은 독립된 보안 환경을 대신하지 않습니다.
- 로그아웃은 공식 원격 세션 철회를 시도하며 실패를 안내합니다. 실패 시 ChatGPT 연결·사용량 설정에서도 접근을 확인하세요. 원격 해제와 본인 기록 삭제는 다릅니다. 기존 토론 기록을 자동 삭제하지 않습니다.
- 개발자에게 비밀번호·인증 토큰·인증 URL·인증 폴더·개인 토론 원문을 보내지 마세요. 문의에는 개인정보를 제거한 오류 코드·발생 단계만 사용합니다.
- 홈페이지는 별도 정적 사이트이며 계정 인증·AI·마이크 기능을 실행하지 않습니다. GitHub Pages와 Releases의 접속·다운로드 처리는 GitHub 정책을 따릅니다. Release의 다운로드 횟수는 고유 사용자 수가 아니며 동일인이 여러 번 받을 수 있습니다.
